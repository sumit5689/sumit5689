- Working across service components including **Authentication, API Gateway, Mobile, HLO, and TM services**.
- Developing and maintaining REST APIs and microservice integrations using **Java and Spring Boot**.
- Implementing authentication and security flows involving **JWT, refresh tokens, OTP validation, session management, and role-based access**.
- Working on API gateway routing, request/response processing, CORS, and service-to-service communication.
- Integrating **PostgreSQL, Redis, and Apache Kafka** for persistence, caching, and event-driven communication.
- Supporting secure mobile-device registration and device-attestation integrations.
- Assisting with deployment, environment configuration, troubleshooting, and testing across development and UAT environments.

An examination management platform built as a **Spring Boot modular monolith** with a React-based user interface.

- Implemented JWT access/refresh-token authentication, Spring Security, BCrypt password hashing, and role-based authorization.

- Worked on question bank, question papers, marks entry, moderation, grading, and result publication workflows.
- Included revaluation, notifications, audit logs, reports, marksheets, certificates, hall tickets, QR verification, and student document uploads.
- Added student self-service capabilities with server-side ownership checks.
- Implemented central SaaS tenant onboarding and application-level tenant isolation, with ongoing security hardening.

**Technology:** Java 21, Spring Boot 3, Spring Security, JWT, React, JavaScript, Vite, Material UI, PostgreSQL, Maven, Linux, NGINX.

### 🏥 Hospital Management System — MediCore HMS

A full-stack hospital management platform being developed incrementally with a microservices-oriented architecture for organization management and clinical workflows.

- Building backend services using **Java 21, Spring Boot 3, and PostgreSQL**.
- Implemented the foundation for organization, hospital, branch, and department hierarchy management.
- Developed scoped identity grants and role-based access for platform, organization, hospital, branch, and department levels.
- Implemented patient registration and search with organization-level UHID uniqueness, branch-level duplicate checks, masked API responses, and encrypted ABHA data at rest.
- Added doctor profiles and recurring schedules with branch/department authorization and overlap prevention.
- Implemented appointment booking, cancellation, rescheduling, completion, patient appointment lists, and doctor queue APIs.
- Using **Redis locks** to reduce concurrent appointment-booking conflicts.
- Building the administration and clinical user interface with **React and Vite**.

**Technology:** Java 21, Spring Boot 3, Spring Security, React, Vite, PostgreSQL, Redis, Flyway, Docker Compose, REST APIs.

[View Hospital Management System Repository](https://github.com/sumit5689/hospital-management-system)
